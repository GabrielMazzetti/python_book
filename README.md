# Introdução ao Python e Web Scraping para Estatística

Este repositório contém o material desenvolvido durante o período de Iniciação Científica, vinculado ao projeto **Métodos de Aprendizado Estatístico para Discriminação e Classificação: Aplicações à Indústria 4.0 – Fase 3** da Universidade Federal de Juiz de Fora (UFJF).

O objetivo deste documento é fornecer uma ponte ágil e aplicada para que estudantes e profissionais de Estatística possam dar seus primeiros passos na linguagem Python, compreendendo como seu ecossistema pode ser utilizado na manipulação de dados, computação numérica e coleta automatizada de informações na internet.

## Estrutura do Material

O conteúdo foi desenvolvido e estruturado sequencialmente para facilitar o aprendizado prático:

* **Capítulo 1 - Introdução:** Contextualização da ferramenta no cenário de dados.
* **Capítulo 2 - Configuração:** Preparação do ambiente RStudio via `reticulate` e uso do `pip`.
* **Capítulo 3 - Fundamentos:** Sintaxe básica, funções e manipulação de listas.
* **Capítulo 4 - Análise Exploratória:** Tratamento e visualização de dados com `pandas`, `seaborn` e `matplotlib` utilizando os datasets *Titanic* e *Iris*.
* **Capítulo 5 - Computação Numérica:** Operações vetorizadas e simulações estatísticas com `numpy`.
* **Capítulo 6 - Web Scraping:** Coleta de dados com `requests` e `BeautifulSoup`.
* **Capítulo 7 - Livros Digitais:** Estruturação de relatórios dinâmicos via Quarto.

## Tecnologias Utilizadas

* **Linguagem Principal:** Python 3
* **Bibliotecas Focais:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `requests`, `BeautifulSoup`
* **Compilação e Relatórios:** Quarto (HTML e PDF) e RStudio

## Como Compilar o Livro

Este material foi escrito utilizando o sistema de publicação científica e técnica **Quarto**. Para compilar os arquivos `.qmd` e gerar o livro nos formatos HTML e PDF, certifique-se de ter o Quarto instalado em sua máquina.

Para renderizar o projeto inteiro, abra o terminal na pasta raiz do repositório e execute:

```bash
quarto render
```
