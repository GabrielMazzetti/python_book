3  Fundamentos

Neste capítulo, iremos contextualizar a lógica de algoritmos ao Python, explicando brevemente a sua sintaxe essencial. A lógica de programação se mantém a mesma independentemente do ambiente computacional, mas detalhes estruturais como a tipagem de dados, a delimitação de blocos e a indexação variam significativamente de uma linguagem para a outra (Sebesta, 2018).

Enquanto linguagens tipadas estaticamente exigem a declaração prévia do tipo de cada variável (seja ela um número inteiro ou um texto), o Python utiliza a tipagem dinâmica, inferindo o tipo do dado no momento de sua execução (Lutz, 2013). Além disso, diferentemente de linguagens que utilizam chaves para agrupar comandos, o Python adota a indentação obrigatória como regra sintática, o que impõe a elaboração de códigos padronizados e altamente legíveis. Outro fator de atenção para os analistas e desenvolvedores é a indexação: ao contrário do R (que é também uma linguagem amplamente utilizada no contexto de análise de dados e Estatística), onde o primeiro elemento de uma estrutura de dados ocupa o índice 1, o Python adota a indexação baseada em zero (0-based), característica compartilhada com linguagens como C e o C++.

3.1 Filosofia, Sintaxe e Tipagem da Linguagem

Grande parte das linguagens de programação surgem (ou evoluem) focadas em otimização de performance para a máquina. Porém, esse não é o caso do Python, que foi concebido a partir de uma filosofia muito bem fundamentada e orientada ao desenvolvedor. O princípio norteador da linguagem é o de que um código é lido muito mais vezes do que ele é escrito. Portanto, a clareza e a legibilidade devem ser prioridades absolutas.

Essa filosofia está muito bem documentada no Zen do Python (PEP 20), um conjunto de princípios que guiam as melhores práticas na linguagem, destacando máximas como “o simples é melhor que o complexo” e “a legibilidade conta” (Peters, 2004).

Para garantir essa legibilidade de forma estrutural, a sintaxe do Python elimina o uso de marcadores visuais excessivos, como as chaves {} ou as expressões begin/end para delimitar blocos de código. Em seu lugar, a linguagem adota a indentação obrigatória. O recuo da margem esquerda não é meramente uma questão de estilo, mas uma regra sintática rígida documentada na PEP 8 (Van Rossum; Warsaw; Coghlan, 2001). Seu objetivo é forçar o programador a organizar, hierarquicamente, as operações, resultando em um código mais limpo.

Além da sintaxe visual, o Python caracteriza-se por uma tipagem dinâmica e forte. Dinâmica porque não exige a declaração prévia do tipo da variável - a própria linguagem infere se o dado é numérico ou textual no momento da atribuição, além de permitir mudanças de valor e de tipo durante o processo de desenvolvimento. Forte porque, uma vez inferido o tipo, o Python não realiza conversões implícitas que possam gerar comportamentos inesperados, garantindo a segurança e a consistência das operações.

3.2 Estruturas de Dados Nativas

Conhecer as estruturas de dados nativas do Python é essencial para armazenar e organizar informações. As principais coleções embutidas na linguagem são as listas (list), as tuplas (tuple), os dicionários (dict) e os conjuntos (set).

No contexto da manipulação de dados e da programação geral, a lista destaca-se como a estrutura mais versátil e frequentemente utilizada. Diferentemente dos vetores atômicos encontrados no R ou dos arrays estáticos comuns no C++, as listas em Python são coleções heterogêneas e dinâmicas. Isso significa que uma única lista pode armazenar, de forma simultânea, números inteiros, valores reais, textos ou até mesmo outras listas em seu interior (Lutz, 2013).

Além da heterogeneidade, as listas são estruturas mutáveis. Após sua criação, o programador ou analista pode alterar seu conteúdo em tempo de execução sem a necessidade de realocar a estrutura inteira na memória. É possível modificar valores existentes através de seus índices, adicionar novos elementos ao final da coleção (utilizando o método append()) ou remover o último item inserido (através do método pop()) (Python Software Foundation, 2026a). Essa flexibilidade de manipulação direta torna as listas uma base poderosa para o tratamento inicial de dados antes de avançarmos para o uso de bibliotecas.

3.3 Estruturas de Controle de Fluxo

A espinha dorsal de qualquer linguagem de programação é a capacidade de direcionar a execução dos algoritmos, através de estruturas de controle de fluxo. Destacam-se, nesse contexto, as condições lógicas e os laços de repetição, que são amplamente conhecidos e utilizados por quem trabalha com códigos, seja qual for o contexto. Em Python, as estruturas de controle de fluxo seguem a filosofia da linguagem - citada neste capítulo - sendo projetadas para serem diretas e facilmente legíveis, se comparadas a outras linguagens de programação.

As estruturas condicionais utilizam as palavras-chave if, elif (uma abreviação de else if) e else. A condição avaliada não exige o uso de parênteses, e o bloco de código subordinado é demarcado de forma simples e intuitiva: através da inserção de dois pontos (:) ao final da instrução, seguida da já mencionada indentação obrigatória.

No que diz respeito às estruturas de repetição, o Python oferece os laços while e for. O laço while opera de maneira tradicional, executando um bloco de código enquanto uma condição permanecer verdadeira. Contudo, o laço for apresenta uma diferença fundamental e vantajosa em relação a linguagens compiladas clássicas. Em vez de iterar primariamente sobre uma progressão aritmética de índices, o for em Python atua como um iterador direto sobre os itens de qualquer sequência, como uma lista ou uma tupla (Python Software Foundation, 2026a).

No âmbito da análise de dados, por exemplo, essa característica permite que o analista percorra os dados de uma coleção diretamente (por exemplo, lendo cada observação de uma variável) sem a necessidade de gerenciar variáveis contadoras, o que reduz significativamente a chance de erros lógicos. Caso uma iteração numérica tradicional seja estritamente necessária, a linguagem fornece uma função embutida range(), capaz de gerar sequências numéricas de forma eficiente. É importante destacar que a função range() não armazena a sequência inteira na memória de uma só vez; ela calcula os valores sob demanda a cada passo da iteração. Consequentemente, sua complexidade de espaço (consumo de memória) é constante, \(O(1)\)1, independentemente de a sequência possuir dez ou dez milhões de elementos (Python Software Foundation, 2026b). Isso evita gargalos de performance e torna o código otimizado.

3.4 Funções e Ferramentas Funcionais

O processo de desenvolvimento de um algoritmo não apresenta obrigatoriedade de práticas que vão além de uma lógica concisa e do respeito à sintaxe da linguagem. Porém, a escalabilidade de um software ou a estrutura de uma análise de dados, por exemplo, exigem boas práticas que são fundamentadas no bom uso das funções (métodos), antes de partir para estruturas mais complexas. No Python, a definição de uma função é realizada através da palavra-chave def, seguida do nome da função e de seus respectivos parâmetros. Assim como nas funções prontas do Python, as funções customizadas também exigem, por padrão da sintaxe, os parênteses logo após o nome da função. Portanto, os parâmetros são criados dentro dos parênteses, e o valor de saída da operação, ao final da função, é especificado pelo comando return.

Contudo, como citado neste capítulo, o Python não se limita ao paradigma procedural; ele incorpora elementos poderosos do paradigma de programação funcional. Para evitar a escrita de laços for muito extensos ao transformar bases de dados, a linguagem fornece funções de alta ordem (higher-order functions), sendo as mais notáveis o map() e o filter() (Python Software Foundation, 2026c).

Para aqueles que estão habituados ao uso da linguagem R, muito usada na Estatística e na análise de dados, essa mecânica é conceitualmente idêntica ao uso de funções apply() (como o lapply() e o sapply()). O objetivo é o mesmo: permitir um processamento de dados mais rápido, conciso e com menos linhas de código. O map() aplica uma mesma transformação a todos os itens de uma coleção de forma simultânea, enquanto o filter() extrai e retorna apenas os elementos que satisfazem uma determinada condição lógica (bem próximo do que faz a função which(), no R).

Essas ferramentas são ainda mais ágeis quando combinadas com as expressões lambda. Uma função lambda é uma função anônima — ou seja, uma função que não precisa ser formalmente nomeada com def e que é criada em uma única linha de código, sendo ideal para operações rápidas ou descartáveis que serão usadas apenas uma vez dentro de um map ou filter (Lutz, 2013).

3.5 Aplicação Prática: Manipulação de Listas

No script a seguir, consolidamos todos os fundamentos apresentados neste capítulo. O exemplo ilustra desde a manipulação direta de uma lista utilizando métodos nativos (como o append() e o pop()), até o uso avançado das funções map() e filter() associadas a funções anônimas (lambda). Por fim, demonstramos a aplicação de uma função customizada, desenvolvida com def(), para o cálculo de uma média simples.

Nota-se, também, o uso das chamadas f-strings (f"texto {variável}") dentro da função print(). Esse é o método mais moderno e recomendado no Python para interpretar textos e variáveis na mesma linha, gerando saídas de telas mais limpas.

Código 
# ---- Definição de uma função customizada ----
def media(lista):
    soma = sum(lista)
    quantidade = len(lista)
    return soma / quantidade

# ---- Criação e manipulação direta da lista ----
valores = [10, 20, 30, 40]
print(f"Lista original: {valores}")

# Uso do append()
valores.append(50)
print(f"Após append (adicionar 50): {valores}")

# Uso do pop()
valores.pop()
print(f"Após pop (remover último elemento): {valores}")

# ---- Uso de ferramentas funcionais (map, filter e lambda) ----

# Uso do map() com lambda
valores_dobrados = list(map(lambda x: x * 2, valores))
print(f"Valores dobrados com map: {valores_dobrados}")

# Uso do filter() com lambda
valores_filtrados = list(filter(lambda x: x > 20, valores))
print(f"Valores > 20 com filter: {valores_filtrados}")

# ---- Aplicação da função customizada ----
resultado = media(valores)
print(f"Média final dos valores originais: {resultado}")
Lista original: [10, 20, 30, 40]
Após append (adicionar 50): [10, 20, 30, 40, 50]
Após pop (remover último elemento): [10, 20, 30, 40]
Valores dobrados com map: [20, 40, 60, 80]
Valores > 20 com filter: [30, 40]
Média final dos valores originais: 25.0
